第一次用，按这个顺序
  1. 登录：启动页点「微软登录」，按窗口里的网址输那八位代码；不想登正版就点「离线账号」随便起个名。
  2. 选版本：去「下载」页，左边「原版游戏」里挑一个装，装完在启动页「我的版本」里点一下设为启动目标。
  3. 启动：回启动页点「开始」。想调内存就去「设置 → 内存与下载」。
下载页怎么用
  1. 原版：右上角能切 BMCLAPI（国内快）和官方源，点「加载版本清单」会列出从 2009 年到现在全部版本，按「最新正式版 / 正式版 / 快照 / 远古」分组。
  2. 装模组：左边点 Mod / 光影包 / 资源包 等，右边直接就是热门榜，不用搜也能挑；有目标就上面搜索框打关键词。
  3. 装下来放哪：自动进这个版本的 mods / shaderpacks / resourcepacks / datapacks，不用手动解压。
  4. 名字看不懂：模组名会自动显示中文，下面是英文原名。
出问题找小助手
  1. 「小助手」页有「帮我看看为什么崩了」，它会读日志并自动修：重复 mod 挪走、缺前置补上、内存不足提示调大。
  2. 也可以在对话框里说人话：「有没有让帧数高一点的模组」「要个好玩点的整合包」，它会按意思去搜。
  3. 不满意就说「再推荐几个」，它会接着上一批继续翻。
  4. 想要一个陪聊 mod，说「给我做一个陪聊 mod」，会给你生成一套 Fabric 模组骨架。
联机
  1. 「联机」页三步：生成开服配置 → 下载官方服务端 → 开服。
  2. 勾着「正版校验」时只有微软正版号能进；不勾就是离线模式，谁拿到地址都能进。
  3. 局域网里直接连「你的内网IP:25565」；外网要先用内网穿透把 25565 映射出去。
导出、分享、更新
  1. 启动页「导出为整合包」：可以把当前版本的 mod 和设置打成一个 zip，勾选框决定带不带游戏设置和启动器设置。
  2. 设置页「分享长征启动器」：打一个包含 exe 和界面的压缩包，发给朋友就能用。
  3. 设置页「更新地址」填一个 version.json 的地址，点「检查更新」就能比对版本。
常见问题
  1. 启动没反应 / 闪退：先去小助手点「帮我看看为什么崩了」，八成是内存或前置问题。
  2. Java 不对：设置 → 其他 → Java 路径，填你 JDK 的 java.exe；1.16 以下建议 Java 8，1.17 以上 Java 17/21。
  3. 游戏目录在哪：启动页信息卡会显示，默认是启动器旁边的 .minecraft 文件夹。
  4. 想恢复默认设置：删掉游戏目录里对应版本文件夹的 options.txt。
